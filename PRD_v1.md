# PRD v1 — Landing Page Home (CRM) Delita Dove

## 1. Project Overview

- **Project Goal:** Membuat landing page publik utama untuk Delita Dove (Wedding Planner & CRM).
- **Target User:** Guest visitor (calon klien) yang belum punya akun.
- **Success Criteria (first-time visitor memahami):**
  1. Delita Dove adalah wedding planner & event organizer terpercaya.
  2. Paket/produk yang ditawarkan (Dekorasi, Gaun, Makeup, dll).
  3. Alasan layak dipercaya (Portfolio & Testimonial).
  4. Cara kontak/booking.

## 2. Technology Stack

- React JS (JSX)
- Tailwind CSS
- Shadcn UI
- Catatan: Supabase tidak termasuk scope PRD v1.

## 3. Current State

- Admin CRM sudah tersedia.
- Halaman publik masih kosong/terbatas.

## 4. User Journey (Main Flow)

1. User membuka Home.
2. Hero section menyapa.
3. User melihat layanan/paket.
4. User melihat portfolio.
5. CTA: konsultasi/booking.

## 5. Functional Requirements

### Area Top (Awareness)

- Hero section elegan bernuansa pernikahan.
- Headline: **"Wujudkan Pernikahan Impian Anda Bersama Delita Dove"**
- Primary CTA: **"Lihat Paket Kami"**

### Area Middle (Value & Trust)

- About section (visi misi).
- Services/Pacakges preview: kategori (Decoration, Attire, Makeup).
- Portfolio/Trust: foto acara sukses.

### Area Bottom (Conversion)

- CTA konsultasi/booking.
- Footer: kontak, alamat (Kupang), dan sosial media.

## 6. Non-Functional Requirements

- Responsif (desktop & mobile)
- Estetika premium, modern, clean & elegant.

## 7. Scope Limitation

- **Included:** Struktur dan layout landing statis.
- **Excluded:** Integrasi data Supabase.

## 8. AI Agent Safety Rules

- Warna soft pastel/cream, elegan.
- Ikuti struktur Tailwind & Shadcn UI yang sudah ada.
- Jangan sentuh admin routes.

## 9. Acceptance Criteria

- Landing statis selesai di route publik.
- Struktur Top/Middle/Bottom terlihat jelas dan premium.
- CTA berfungsi (minimal scroll/arah ke form).
- Tidak ada backend/database integration.

## 10. Hasil yang Diharapkan

- Halaman `/guest` menampilkan komponen landing sesuai desain.
